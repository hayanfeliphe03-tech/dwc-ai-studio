# DWC AI Studio

Laboratório experimental da Digital Web Creations para explorar agentes inteligentes, engenharia de software com IA e experiências digitais premium.

## Estado atual

Projeto em fase inicial. A primeira entrega será uma landing page responsiva, seguida por protótipos pequenos para testar ferramentas de IA de forma segura e com prioridade para opções gratuitas.

## Princípios

- Priorizar ferramentas gratuitas e open source quando viável.
- Não publicar senhas, tokens ou chaves de API.
- Conferir as licenças antes de reutilizar código ou modelos.
- Documentar limitações e custos antes de integrar serviços externos.
- Não prometer autonomia ou capacidades que ainda não foram implementadas.
